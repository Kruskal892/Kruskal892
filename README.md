- **Reusable UI:** Composable React and Radix UI components, caller-controlled styling, light/dark themes, and Storybook examples for component states and keyboard interactions.

- **Search experiences:** Algolia integrations with filtering, pagination, and reusable search components.

- **Backend foundations:** Typed Express APIs, Prisma-backed MongoDB user persistence, Redis-backed OTP expiry and request limits, and JWT cookie issuance.
- **API documentation:** Swagger contracts and diagrams explaining service responsibilities and authentication request flows.

## Featured Project

### [Microservice Eshop](https://github.com/Kruskal892/Microservice-SaaS-E-commerce)

An **ecommerce foundation in development**, combining a Next.js frontend with an Express API gateway and authentication service in a TypeScript monorepo.

- **Service architecture:** Nx and npm workspaces organize the client, backend services, and shared UI, error handling, Prisma, and Redis clients.
- **Authentication backend:** Email OTP registration, bcrypt password hashing, MongoDB account persistence through Prisma, and login that issues access and refresh JWTs in HTTP-only cookies.
- **OTP and email:** Redis-backed OTP expiry, resend cooldowns, request limits, and failed-attempt tracking, with Nodemailer and EJS email templates.
- **API gateway:** Request proxying, CORS configuration, IP rate limiting, request logging, and shared error handling.
- **Shared UI library:** React and Radix UI components for forms, OTP entry, dialogs, menus, tabs, and tooltips, with semantic Tailwind CSS tokens, light/dark themes, and Storybook documentation.
- **Frontend foundation:** Responsive header with sticky navigation, login and registration form scaffolds, React Hook Form + Zod validation, and an OTP entry UI with resend countdown feedback.
- **Development workflow:** Swagger API documentation, GitHub Actions check configuration, and an authentication-service Dockerfile.

**Frontend:** Next.js · React · TypeScript · Tailwind CSS · Radix UI · React Hook Form · Zod · Storybook

**Backend:** Node.js · Express · Prisma · MongoDB · Redis · JWT · bcryptjs · Nodemailer · EJS · Swagger

**Workspace & tooling:** Nx · npm workspaces · GitHub Actions · Docker

**Current stage:** Backend registration and login logic and shared UI foundations are implemented. Client authentication forms still use local feedback and are not connected to the backend. Protected-route authorization, token refresh/logout, and commerce APIs remain unfinished or planned; password recovery requires security hardening. Live integrations and deployment are unverified.
